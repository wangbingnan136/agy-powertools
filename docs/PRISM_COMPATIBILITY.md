# Prism 功能接入进度

以 [Obsidian Prism `v1.0.7`](https://github.com/RMvdesi/obsidian-prism) 的公开功能为规格参考。Powertools 保持 MIT：独立实现，不导入参考仓的源码、图片、安装器或第二套 Sidecar。

## 已接入，可在 Powertools 设置中找到

| 位置 | 功能 | 与现有设计的分工 |
| --- | --- | --- |
| 界面与光学 | 四套深浅配色、强调色、圆角、代码字体、场景预设、输入区与侧栏样式、动效、像素桌宠 | 默认保留原生配色；光学配色让位于已有的自定义消息气泡。重度动效和桌宠默认关闭。 |
| 界面与光学 | 水波试管和原生圆环切换 | 沿用同一个输入框入口和已有上下文数据，不多放一套遥测。不固定模型的实际窗口上限。`/compact` 仅填入空输入框，不发送。 |
| 交互与工作台 | 推理档位滑杆及模型档位记忆、长代码折叠、悬停大纲、跳轮快捷键、会话选区菜单 | 沿用可见的原生档位；文件右键仍由现有菜单负责，选区菜单按需启用。 |
| 交互与工作台 | 本地行内 Git Diff、手动挑选媒体或字体预览 | Diff 只针对当前会话已登记的本地 Git 工作区和普通仓库；不读取未跟踪文件，不调用仓库自定义外部 Diff 或过滤器。预览只拿到选择器提交的文件，不启动预览服务器。 |
| 实验与归档 | Studio 首页统计、Chat 文件夹、本地图片/视频壁纸，设置备份和还原 | 复用既有看板数据；Chat 文件夹只整理列表，不改项目权限；壁纸不上传且仅保留在当前窗口；导入不会启用多账号或替用户确认敏感设置。 |

## 尚未做到 1:1

- 思考译文、标题自动翻译和供应商设置未连接到实时客户端，不会外发会话文字。已有的服务实现仅通过模拟上游测试；仍需接入明确的用户授权和受支持的上游 API。
- 预览仅涵盖手动选择的常用图片、视频、音频、字体。未接通裸链接接管、大文件 HTTP 流式网关、表格、PDF/HTML 或 Mermaid 源预览。
- 不修改客户端会话数据库或自动搬移历史。旧会话归档的实现仅使用测试夹具验证，未开放到产品。
- Prism 新设置有五语版本；现有 Powertools 与宿主界面没有补齐所有日文和粤语词条。未启用跨插件窗口主题同步、Beta 更新通道或参考项目的安装器。
- 本地包与自动化测试不能证明真实客户端的视觉、性能和交互与参考项目一致。这些需在受支持的客户端内单独验收。
